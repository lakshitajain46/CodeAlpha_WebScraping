# CodeAlpha Web Scraping Project

## Objective
This project extracts book information from an online bookstore using Python web scraping.

## Website Used
https://books.toscrape.com/

## Technologies Used
- Python
- BeautifulSoup
- Requests
- Pandas

## Features
- Extracts book titles
- Extracts prices
- Extracts ratings
- Saves data into CSV format

## Output
books_data.csv

## How to Run

```bash
pip install -r requirements.txt
python main.py
